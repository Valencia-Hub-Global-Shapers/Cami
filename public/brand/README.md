# Camí logo files

| File | Use |
| --- | --- |
| `cami-logo.svg` / `.png` | Full logo (mark + wordmark) on light backgrounds |
| `cami-logo-light.svg` / `.png` | Full logo with a cream wordmark for dark backgrounds |
| `cami-mark.svg` / `.png` | Mark only, transparent background |
| `cami-app-icon.svg` / `.png` | Mark on a cream rounded square (favicon / avatar) |

The wordmark is set in Fraunces SemiBold and converted to outlines, so the
SVGs render the same without the font installed. PNGs are transparent
(except the app icon) and exported at 4x (logo, 839x272) or 512x512 (mark, icon).

Colours: terracotta `#C1652F`, route green `#2F6F65`, ink `#211E19`,
cream `#FBF6EE`.
